# Tech Q Launchpad

Project Overview:
Create a modern, high-converting corporate website for Tech Q, an IT solutions company. The website should establish Tech Q as a cutting-edge, reliable, and innovative partner for businesses looking to scale digitally.

Company Services:

Custom Website Development

Business Process Automation

IT Network Solutions (Security & Infrastructure)

Mobile & Web App Design

Color Palette (Techy Blue Theme):

Primary: Deep Navy Blue (#0A192F or #1B2A4A) – for headers, footers, and backgrounds.

Secondary: Bright Cyber Blue (#00A8FF or #0088CC) – for buttons, links, and interactive elements.

Accent: Electric Cyan (#5CE0FF or #00E5FF) – for hover effects, highlights, and gradient overlays.

Background: Very light cool gray/blue (#F4F8FB) for contrast sections.

Text: Pure White (#FFFFFF) on dark backgrounds and Dark Slate (#1E293B) on light backgrounds.

Required Pages & Sections:

Homepage (Hero Section):

Full-width background with a dynamic mesh gradient or abstract circuit board pattern using the Techy Blue palette.

Headline: "Future-Proof Your Business with Tech Q."

Sub-headline: "Custom Websites, Smart Automation, and Secure Networks—Built for Scale."

Two prominent CTAs (Call to Action): "Get a Free Quote" (Cyan button) and "View Our Work" (Outlined white/blue button).

Include floating 3D elements or micro-interactions (like glowing orbs or rotating geometric shapes).

Services Section:

Display the 4 core services (Websites, Automation, Network Solutions, App Designs) in clean card-style layouts.

Each card should have a subtle blue gradient border and a hover effect that lifts the card and changes the icon to Cyan.

Icons should be minimalist line-art in the primary blue.

About Us / Tech Vibe:

A split-screen layout. Left side: Text explaining the company's mission (innovation, security, speed). Right side: A collage of code snippets, server racks, and mobile wireframes overlapping in a tech-art style, tinted blue.

Portfolio/Case Studies:

A grid layout showing 3-4 past projects with a "Techy Blue" overlay that reveals the client name and result on hover.

Testimonials:

A carousel with client quotes. Use dark navy backgrounds with bright cyan quotation marks.

Footer:

Dark navy background. Include contact info, social media links (LinkedIn, Twitter/X, GitHub), and a quick navigation menu. Add a small tagline: "Tech Q: Code. Connect. Create."

Design & Functionality Requirements:

Typography: Use a sans-serif font like Inter or Space Grotesk for a futuristic, clean feel. Headings should be bold (700 weight), body text light (400 weight).

Animations: Smooth scroll-triggered animations (fade-ups). Elements should slide into view as the user scrolls down.

Responsiveness: Must be fully mobile-responsive, with the navigation bar collapsing into a sleek hamburger menu on tablets and phones.

Loading Speed: Optimize for fast loading (use WebP images and lazy loading).

Interactive Element: Include a live "System Status" widget in the bottom corner that shows green "All Systems Operational" dots for a techy, IT feel.

Tone & Voice:
Professional, confident, and forward-thinking. Avoid overly complex jargon; keep it clear but technically impressive.
